# Agent Rules for Omni Project

## Git Commit Rules
When making git commits, agents MUST:
1. Always use `git commit` to commit changes instead of saving them without version control.
2. Ensure the commit message contains exactly what was changed, why it was changed, and full context for Codex or other AI agents, so that context is available in the future.
3. Be as descriptive as possible in the body of the commit message to explain the rationale behind architectural and code changes.
