# Architecture Decision Record Template

Use this template for any proposed change that affects the frozen Omni Universal Source Import Architecture v1.0.

## ADR-000: Title

- Status: Proposed
- Date: YYYY-MM-DD
- Owners: TBD
- Related documents:
  - [Architecture Freeze Plan](./architecture-freeze-plan.md)
  - [Architecture Principles](./architecture-principles.md)

## Context

Describe the problem, pressure, limitation, or opportunity that requires an architectural decision.

## Decision

State the decision clearly. Include the scope and the intended steady-state design.

## Affected Modules

List affected layers, modules, data models, APIs, workflows, jobs, or UI surfaces.

## Compatibility And Migration

Explain whether the decision preserves backwards compatibility. If it does not, document the migration strategy and rollout plan.

## Consequences

Describe expected benefits, tradeoffs, operational risks, and long-term maintenance effects.

## Alternatives Considered

List credible alternatives and why they were rejected.

## Principle Updates

State whether [Architecture Principles](./architecture-principles.md) must change. If yes, include the proposed changes.

## Acceptance Checklist

- [ ] Preserves backwards compatibility or includes a migration strategy.
- [ ] Identifies affected modules.
- [ ] Updates Architecture Principles if required.
- [ ] Documents consequences and alternatives.
- [ ] Has an owner and status.
